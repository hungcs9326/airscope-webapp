# AirScope｜空氣品質巡檢板

一個以環境工程學習情境設計的互動式單頁 Web App。輸入 PM2.5、CO₂、TVOC 與相對濕度後，可取得環境風險分數、主要影響項目與改善建議，並保存歷史紀錄、繪製趨勢圖及匯出 CSV。

## 使用方式

直接開啟 `index.html`，或使用本專案的 GitHub Pages 網址。

## 主要功能

- 四組快速測試情境。
- 即時風險判讀與具體改善建議。
- localStorage 保存最多 30 筆巡檢紀錄。
- Canvas 趨勢圖、單筆刪除與清除全部。
- UTF-8 CSV 匯出。
- 響應式介面與深色模式。

詳細設計請見 [`SPECIFICATION.md`](./SPECIFICATION.md)。
