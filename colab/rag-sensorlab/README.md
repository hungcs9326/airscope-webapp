# AirScope SensorLab｜空品感測器避坑教練

用 EPA 技術手冊回答「感測器讀值能不能這樣解釋？」的文件問答作品。角色「阿澈」以台灣繁體中文協助查證，區分文件依據與情境建議，並顯示實際來源片段及 PDF 頁序。

## 直接開啟 Colab

- **繳交用 RAG02：** https://colab.research.google.com/github/hungcs9326/airscope-webapp/blob/main/colab/rag-sensorlab/RAG02_SensorLab.ipynb
- RAG01 建庫： https://colab.research.google.com/github/hungcs9326/airscope-webapp/blob/main/colab/rag-sensorlab/RAG01_SensorLab.ipynb
- `rag-data.zip` 是已建立的真正向量庫，不是只有原始文件。RAG02 內已填入固定 Git 版本的公開下載網址及 SHA-256。

此資料夾是獨立作業，沒有更改原本 AirScope 網站或 EcoClue 筆記本。

## 使用方式

1. 開啟 RAG02，按「在雲端硬碟中儲存副本」，填寫姓名、學號與系級。
2. Colab 左側鑰匙圖示 → Secrets，沿用名稱 **`Groq`**，開啟這份新筆記本的 Notebook access。不要把金鑰寫進程式、聊天或截圖。
3. 使用 Python 3／CPU 執行階段，按「執行階段 → 全部執行」。第一次需安裝套件、下載嵌入模型，時間依 Colab 網路及資源而異。
4. 最後一格持續執行是在維持 Gradio 服務。看到嵌入介面或 `gradio.live` 網址後即可操作。
5. 正式展示前，確認畫面已讀取 Groq，並取消勾選「純檢索預覽」。如果修改了 Secret，重跑金鑰設定與建立介面的儲存格。
6. 分享自己的副本時，設為「知道連結的任何人 → 檢視者」。別人的執行階段仍須使用自己的 Groq 金鑰；分享筆記本不會分享 Secrets。

沒有金鑰也能執行 ZIP 下載、載入、檢索與介面，但會明確標示為純檢索預覽；這不能當成已完成 LLM 對話。

## 實際修正與驗證

最初直接用中文問「濕度高時 PM2.5 讀值變高」，前四個片段在 PDF 31、174、142、95 頁，未出現測試所需的 humidity／moisture 關鍵字。先加入一般濕度英文查詢，再核對原文、改用手冊中的 moisture／optical PM sensors 術語，最終候選為 31、96、174、96 頁，其中第 96 頁兩個片段能提供光學 PM 感測器受水分干擾的直接依據。這是檢索改善的證據，並非 LLM 回答品質的正式評分。

- 真實驗證：ZIP SHA-256、各檔案雜湊、重新載入、508 個向量、384 維、單位向量、五組中英文檢索及 Gradio 介面設定。
- 另以 Gradio 的真實 HTTP 介面測試送出、多輪文字區塊回傳、追問與清除功能；詳見 `ui_validation.json`。測試使用明確標示的純檢索預覽，沒有偽裝成 Groq 生成或瀏覽器截圖。
- 多輪訊息正規化與無效引用拒絕使用明確標示的模擬客戶端做協定測試。
- **未在此環境呼叫學生的 Groq 金鑰；沒有把模擬回答當成實際作業成果。** 請在自己的 Colab 完成真實對話並保留結果。
- 詳細紀錄：`validation_before_query_expansion.json` 與 `validation_report.json`。
